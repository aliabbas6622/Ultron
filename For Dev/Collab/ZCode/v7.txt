New engines (all contract-clean, dependency-direction gate green):
- core/router.py - adaptive L0-L4 model routing (06): privacy/difficulty/
  tool-use/latency rules, deterministic tie-breaks, fallback chains.
- core/supervisor.py - self-diagnostics: CircuitBreaker (closed/open/half-

  (publishes ComponentDegraded/Recovered on transitions only).
- core/scheduler.py - recurring jobs (JobStore JSON at ULTRON_HOME), injected
  clock, exception-isolated run_due.
- core/plans.py - persistent resumable plans: per-step checkpoints, status
  precedence, PlanStore JSON per plan, corrupted-file tolerance.
- core/workers.py - multi-agent workers: bounded ThreadPool parallelism,
  sub-budgets via Budget.child(), isolated cancellation (parent.cancel kills
  the pool; one worker's failure never kills siblings).
- skills/ - self-contained skill bundles (TOML, version+content-hash,
  validate_name path-traversal guard, skill_system_section prompt injector).
- contracts/fabric.py - distributed scaffold with the 07 invariant encoded:
  PairingGrant REQUIRES human_approval_token (ContractViolationError
  otherwise), advertising is not authorization, PairingLedger revocation.
