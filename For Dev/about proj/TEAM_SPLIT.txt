FLAG to DEEPSEEK: adapters/model/deepseek.mojo does not compile yet under Mojo 1.0.0 stable:
  - `comptime _httpx = Python.import_module(...)` etc. — can't call a raising function in a comptime initializer; do this at runtime (e.g. in __init__ or a cached instance field), not as a `comptime`.
  - missing `from std.python import PythonObject`.
  - `self.api_key = api_key^` etc. on an immutable-borrow arg — take the arg as `var api_key: String` if you intend to transfer it, or drop the `^` and assign directly.
  - same `List[Capability]` return needs `return caps^` (see contract.mojo fix above).
  Also still has `fn` throughout — needs the same `fn` -> `def` pass as contract.mojo/models.mojo got.
